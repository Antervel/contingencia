# E1-06: Catch-all and recipient policy

**Epic:** E1 (mta + imap prototype)
**Size:** M
**Depends:** E1-05
**Hypotheses covered:** H4, H10

## Context

With the copy rule in place (E1-05), the next behaviour to build is the optional **catch-all**:
mail for a client domain address that has no own mailbox must be copied into the domain's
dedicated catch-all mailbox. The BCC map from E1-05 only has entries for the fixture mailboxes,
so the catch-all has to be added without disturbing the exact-address behaviour (H4).

The second half of the ticket covers the **recipient policy** (EPIC FR-3): the administrator can
choose between "accept any address" and "listed addresses only" (H10). The prototype starts in
the accept-any mode (relay domains only) and must keep both behaviours testable.

## What to do

1. Add the catch-all BCC entry to the `recipient_bcc` table (`texthash`), for the client domain(s)
   that have a catch-all in the fixtures (`client.test`), pointing at the catch-all internal
   delivery address (`_catchall^client.test@copies.invalid`). Leave `other.test` without a
   catch-all, as in the fixtures.
2. Add a relay recipient map (`relay_recipient_maps`) in Postfix, backed by a table file, to
   support the "listed addresses only" policy (EPIC FR-3 / H10). Keep the accept-any mode
   available while testing.
3. Reload Postfix and run the tests below.

## Acceptance criteria

- **H4 PASS:** an exact BCC entry takes precedence over the `@domain` catch-all entry, so a
  known address is not also copied to the catch-all; an unknown address in a catch-all domain is
  copied to the catch-all mailbox.
- **H10 PASS:** both "accept any address" and "listed addresses only" can be configured and
  behave as described in the PRD.

## How to test

```
prototype/tests/lib/sink.sh clear
docker compose exec imap sh -c 'rm -rf /var/mail/vhosts/client.test/_catchall/Maildir/new/* /var/mail/vhosts/client.test/_catchall/Maildir/cur/*'

# Unknown address in a catch-all domain -> relayed + BCC copy to catch-all.
swaks --server 127.0.0.1:2525 --from sender@sender.test --to nobody@client.test \
      --header 'Subject: catch-all test' --body 'hello catch-all'

# Known address -> own mailbox only (no catch-all copy).
swaks --server 127.0.0.1:2525 --from sender@sender.test --to alice@client.test \
      --header 'Subject: exact address test' --body 'hello alice'

# Policy: with the listed-only policy active, unlisted relay recipients are rejected.
swaks --server 127.0.0.1:2525 --from sender@sender.test --to someone@elsewhere.test \
      ; echo "exit: \$?"
```

## Notes and pitfalls

- The catch-all must be added without disturbing the exact-address BCC entries from E1-05;
  Postfix applies the full-address lookup before the domain catch-all.
- The "listed addresses only" policy is the administrator's choice (FR-3); the prototype should
  be able to switch between it and the accept-any default through the relay recipient map.
